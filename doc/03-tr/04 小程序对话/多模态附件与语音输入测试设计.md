# 测试范围

- `hipp-api`：`/mp/chat/upload`、发送三路径（blocking / stream / WS）的 `files`、消息 `attachments` 落库与列表返回、合计/单文件超限、人工客服拒附件、可选 `audio-to-text`。
- Dify Mock：请求体含 `files` 且 `transfer_method=remote_url`（或降级 `local_file`）。
- `hipp-web` / `hipp-uni`：选附件、预览删除、发送前校验、气泡展示、语音转写填入（手工为主）。
- 不覆盖：视频、人工客服附件成功路径。

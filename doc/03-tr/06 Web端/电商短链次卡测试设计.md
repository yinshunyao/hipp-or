# 测试范围

- 权益创建/作废/过期；短链 redeem；免登录一次需求分析；话题结束后不可再开。
- 渠道订单幂等；小红书回调生成短链；未配置发货 URL 时仍可管理台查链。
- 次卡不扣钱包；与正式登录扣费互不干扰。

# 测试用例

| 编号 | 前置 | 步骤 | 预期 | 自动化 |
|:---|:---|:---|:---|:---|
| E1 | 管理台创建 unused 权益 | 打开 `/a/{token}` | 页内可聊（无侧栏「新会话/归档」），可发消息 | 手工 |
| E2 | E1 后话题结束 | 再打开同一 `/a/{token}` | 自动只读展示结果；他人打开同链亦可看；POST redeem 拒绝 | 手工 |
| E3 | unused 权益 | 管理台作废后再打开短链 | 不可核销 | 手工 |
| E4 | 同一 xhs 订单回调两次 | 发两次 notify | 仅一条权益/短链 | 手工/建议 pytest |
| E5 | 次卡用户完成话题 | 查 manager 流水 | 无 `consume_session` 扣款 | 手工 |
| E6 | 正式登录用户 | 正常结束话题 | 仍按原规则扣费 | 手工 |
| E7 | `HIPP_XHS_DELIVER_URL` 未配 | 回调成功 | 订单已支付、短链可查 | 手工 |
| E8 | 已支付订单 | 管理端渠道订单点退费 | 状态已退费；短链不可打开；提示资金在千帆退 | 手工 |
| E9 | 已支付后完成咨询 | 看渠道订单 | 状态已核销；再退费仍可点，短链失效 | 手工 |
| E10 | 已退费订单 | 再点退费 | 拒绝重复退费 | 手工 |
| E11 | 管理员 | 渠道订单页点「线下出链」 | 生成 1 条已支付订单+短链，可复制；打开可完成 1 次分析 | 手工 |
| E12 | 管理端次卡短链列表 | 查看状态/渠道/操作 | 中文状态与渠道；短链为 https；可复制链接；未消费可退费作废 | 手工 |

# 业务错误码（建议）

| code | 含义 |
|:---|:---|
| 46010 | 短链无效或过期 |
| 46011 | 已用尽 |
| 46012 | 已作废 |
| 46013 | 次卡用户不可用该场景/超额建会话 |

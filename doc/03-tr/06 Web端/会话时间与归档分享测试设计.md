# 测试范围

`hipp-web` 会话消息时间，以及归档话题的分享链接。接口依赖已运行且已迁移的 `hipp-api`。自动化：本次不编写脚本，以下用例手工执行。

# 测试用例

| 编号 | 前置条件 | 操作步骤 | 预期结果 | 自动化 |
|:---|:---|:---|:---|:---|
| WEB-26 | 已登录，会话里已有往来消息 | 打开该会话 | 用户消息和助手消息下方有日期和时间，格式为年-月-日 时:分 | 否 |
| WEB-27 | 已登录，当前会话可发送 | 发送一条消息 | 新消息立即带有时间，发送、回复和归档行为与改版前一致 | 否 |
| WEB-28 | 已登录，一条已完成、仍在「最近」、尚未分享的话题 | 悬停分享图标，确认提示为「分享」后点击，再到别处粘贴 | 提示链接已复制，粘贴内容是 `/share/` 加令牌，不是会话数字编号。该行变为链接图标和停止分享图标，悬停提示分别为「复制链接」「停止分享」。图标靠在一起，间距小于标题和按钮组之间的空隙，标题比按钮分散排列时露出更多字 | 否 |
| WEB-32 | 已登录，上一条已分享 | 悬停链接图标，确认为「复制链接」后点击 | 剪贴板仍是原来的链接，令牌不变 | 否 |
| WEB-33 | 已登录，上一条已分享，链接可打开 | 悬停停止分享图标，确认为「停止分享」后点击，再打开原链接 | 提示已停止分享。页面说明分享不存在或已失效 | 否 |
| WEB-34 | 已登录，已打开一条已分享话题 | 看话题标题旁的操作，悬停后点击停止分享图标 | 标题旁是图标而不是「复制链接」「停止分享」文字。悬停能看到名称，点击后停止分享 | 否 |
| WEB-29 | 未登录 | 在新窗口打开上一步的链接 | 只看到该话题的聊天内容和「联系我们」。没有左侧菜单、最近会话和输入框。点击「联系我们」弹出关于我们 | 否 |
| WEB-30 | 已登录，一条仍在进行中的话题 | 查看该行，并直接调用分享接口 | 没有分享入口。接口拒绝 | 否 |
| WEB-31 | 已分享的话题被延续，或链接令牌不存在 | 再次打开分享链接 | 页面说明分享不存在或已失效，不展示他人会话内容 | 否 |
| WEB-35 | 已登录，在需求/商业场景页把话题聊到结束 | 查看右上角 | 出现分享图标与「归档」按钮；进行中时无分享 | 否 |

# 测试范围

`hipp-web` 的登录、话题列表、单会话、需求场景、资料与密码。首版不测商业场景入口（已隐藏）。资金账户见同目录 `个人资金账户测试设计.md`。接口依赖已运行的 `hipp-api`。自动化：本次不编写自动化脚本，以下用例手工执行。

# 测试用例

| 编号 | 前置条件 | 操作步骤 | 预期结果 | 自动化 |
|:---|:---|:---|:---|:---|
| WEB-01 | 未登录 | 打开站点根路径 | 进入登录页 | 否 |
| WEB-01b | 已登录 | 打开站点根路径或登录页 | 进入需求会话页 | 否 |
| WEB-01c | 已登录 | 查看侧栏导航；访问 `/business` | 侧栏只有「需求」，无「商业」；`/business` 重定向到 `/requirement`。没有「接待」，也没有客户对话 | 否 |
| WEB-01e | 已登录 | 点击头像下方的「联系我们」 | 只弹出关于我们，不打开资料层 | 否 |
| WEB-01d | 任意页 | 点击「需求」或「智臻善算」 | 打开 `http://hipp.site/`。导航中没有首页和「我的」 | 否 |
| WEB-02 | 登录页 | 不勾选协议点击登录 | 按钮不可用或提示先同意协议 | 否 |
| WEB-03 | 有效手机号 | 获取验证码并短信登录 | 进入话题页或 redirect 目标；本地存有 access token | 否 |
| WEB-04 | 已有密码账号 | 切换账号密码并登录 | 进入话题页，请求头带 Authorization | 否 |
| WEB-05 | 首次短信注册且需设密码 | 登录后在展开的修改密码里不填旧密码，设置 8–20 位新密码 | 提交成功，随后用新密码可登录；不进入单独的改密页 | 否 |
| WEB-06 | 已登录普通用户，有归档话题 | 打开话题页，搜索标题，置顶、改名、删除各一次 | 列表随接口结果更新；删除前有确认 | 否 |
| WEB-07 | 已结束且智能体可用的话题 | 在列表选择继续对话，或在会话里再发一条消息 | 继续对话进入原会话；再发送会新建会话并出现回复 | 否 |
| WEB-07b | 已登录，打开 `/chat/{旧id}` 且话题已结束、智能体可用 | 再发一条消息并等回复开始 | 新建会话；地址栏变为 `/chat/{新id}`；侧栏高亮新会话；消息写入新 id 而非旧 id | 否 |
| WEB-07c | 库中存在同智能体未结束、已扣费、无用户/助手消息的空壳 | 打开需求场景页 | 不进入该空壳；空壳被软删或不再作为进行中会话返回；可新建或进入有内容的进行中会话 | 否 |
| WEB-08 | 进行中的智能体会话 | 发送一条消息 | 先出现用户气泡，助手内容逐步增长；失败时可重试 | 否 |
| WEB-09 | 已结束且智能体可用的会话 | 点击「联系我们」 | 弹出关于我们，不进入人工会话 | 否 |
| WEB-10 | 已登录，需求场景有可用智能体 | 打开需求页，上滚加载更早归档，点击一条归档 | 当前会话可发送；归档进入只读或历史会话页 | 否 |
| WEB-11 | 已登录（`SHOW_BUSINESS_SCENE=false`） | 尝试打开商业页或侧栏找「商业」 | 无入口；直链 `/business` 进需求页。恢复开关后再测商业场景全流程 | 否 |
| WEB-12 | 角色含人工客服 | 打开需求会话页 | 导航没有接待；左侧不出现分配给自己的客户对话 | 否 |
| WEB-13 | 已登录 | 点击左下角头像，展开编辑资料，修改姓名昵称手机性别并上传头像 | 资料层展示更新后的名称与头像，地址仍停留在会话页 | 否 |
| WEB-14 | 已登录 | 切换深色模式后刷新；点击关于我们 | 主题保持。弹窗为成都智臻善算科技有限公司，含殷先生、17302868369、信用代码、地址和备案号 | 否 |
| WEB-15 | 已登录 | 退出登录后访问 `/topics` | 回到登录页，接口不再带旧令牌 | 否 |
| WEB-16 | 已登录，当前需求会话已有来回且未结束 | 点击「新会话」，再发一条消息 | 出现空白会话并可发送；旧会话仍在「最近」，标题是模型概括的短标题，而不是用户原文开头截断 | 否 |
| WEB-22 | 已登录，「最近」里有标题为原文开头的旧会话 | 展开该场景的「最近」 | 标题改成概括，例如「Veo停车识别算法需求」，不再以「# 需求…」这类原文开头展示 | 否 |
| WEB-23 | 已登录，最近里有一条有过回复的会话 | 点击该行「归档」，再点下方「归档」 | 该会话离开「最近」；归档列表中能看到它的时间、标题和 token 消耗。再打开仍可查看 | 否 |
| WEB-17 | 已登录，打开一条没有消息的草稿 | 不发送，直接再点「新会话」 | 不新增一条「最近」记录 | 否 |
| WEB-18 | 已登录，需求会话可回复 | 发送一条消息，观察助手区域 | 发送后立即出现正在回复；正文随文字增长并带光标，而不是整段结束后一次出现 | 否 |
| WEB-19 | 助手回复含 think 段，其后有正式回答 | 查看该条回复，点击「深度思考」，再点一次 | 默认只见中文标题（可带用时），不见英文 think 标签；正式回答仍在标题下方。点击后展开思考内容，再点收起。思考尚未结束时标题为「深度思考中...(Ns)」且秒数增长，结束后变为「深度思考 (Ns)」 | 否 |
| WEB-20 | 进行中的智能体会话 | 发送一条会流式回复的消息，看用户气泡与助手「正在回复…」是否同屏 | 出现「正在回复…」时用户侧不再显示「发送中」；二者不同时出现 | 否 |
| WEB-21 | 进行中的智能体会话，回复含较长深度思考 | 发送后等待超过 90 秒，期间助手仍在输出 | 连接不被 90 秒总时长掐断，已出现的正文不被换成「发送失败，请稍后重试。」 | 否 |
| WEB-26 | 已登录但余额不足以支付会话咨询费 | 上传 Word 成功后发送，或直接发纯文字 | WS/HTTP `code=46005`；助手气泡为余额不足文案；跳转 `/wallet`；不是笼统「发送失败」；附件可出现在用户气泡但不代表消息已受理 | 否 |
| WEB-24 | 已登录，头像为空或仍是系统占位图 | 看左下角头像，再点开头像看资料层 | 两处都是姓氏圆印，不出现破图或风景占位图标。上传自选头像后两处改为该图片 | 否 |
| WEB-25 | 已登录 | 查看需求、新会话、归档、联系我们和发送 | 这些入口带线性图标。无「商业」入口。点击后的页面跳转、建会话、归档和发送正常 | 否 |

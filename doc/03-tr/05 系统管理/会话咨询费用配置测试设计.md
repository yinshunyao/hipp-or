# 测试范围

管理端会话费用页与 `/vadmin/billing/session-fee/*`；用户端 `GET /wallet/session-fee`。自动化：本次不编写。

# 测试用例

| 编号 | 前置条件 | 操作步骤 | 预期结果 | 自动化 |
|:---|:---|:---|:---|:---|
| FEE-01 | 迁移已执行 | 打开会话费用页 | 全局金额为 0.10（或已保存值） | 否 |
| FEE-02 | 管理员登录 | 将全局改为 0.20 并保存 | 再次打开仍为 0.20 | 否 |
| FEE-03 | 存在手机号用户 | 搜索手机号片段 | 列表命中该用户，无专属时生效=全局 | 否 |
| FEE-04 | 选中用户 | 设定专属 0.05 | 列表显示专属与生效 0.05 | 否 |
| FEE-05 | 用户有专属 | 清除专属 | 生效回到全局 | 否 |
| FEE-06 | 已登录 Web | 打开 `/wallet` | 副标题金额与解析费用一致 | 否 |
| FEE-07 | 非法金额 -1 | 保存全局 | 拒绝并提示 | 否 |
| FEE-08 | staff 登录管理端 | 打开侧栏 | 可见「计费配置 / 会话咨询费用」 | 否 |

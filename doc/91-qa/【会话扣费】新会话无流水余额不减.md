# 问题描述

# 根因分析

1. Web「新会话」在「同智能体且当前会话无发言」时直接清空本地消息并 return，**不调用** `createChatSession`，因而从不触发服务端扣费。
2. 扣费原先只挂在 `create_session`；复用旧草稿再发消息也不会补扣。
3. S2S deduct 本身可用（手工探测可扣成功）；问题在触发时机。

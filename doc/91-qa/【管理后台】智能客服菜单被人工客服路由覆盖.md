# 问题描述

访问 `http://hipp.site/or/manager/` 时，侧栏不再出现「智能客服 / 智能客服管理」，无法配置 Dify 智能体的 `api_server` / `app_key`，后端对话无法联通 Dify。

# 关联文档

| 类型 | 文档路径 |
|:---|:---|
| 原始需求 | `hipp-or/doc/01-or/【智能客服管理】Dify智能体接入管理.md` |
| 开发设计 | `hipp-or/doc/02-dr/03 智能客服管理/Dify智能体接入管理设计.md` |
| 测试设计 | `hipp-or/doc/03-tr/03 智能客服管理/Dify智能体接入管理测试设计.md` |

# 根因分析

1. `hipp-admin` 的 `asyncRouterMap` 曾声明 `/agent` → `/agent/manager`（`AgentManager.vue`）。
2. 上线人工客服时，提交把该段路由**改成了** `/mp-staff`（客服工作台），而不是在旁新增，导致前端强制合并的 `/agent` 菜单消失。
3. `permission.ts` 仍会查找 `path === '/agent'` 覆盖后台菜单；前端无此条目后，侧栏不再展示智能客服管理页。

# 涉及文件

- `hipp-or/hipp-admin/src/router/index.ts`：恢复 `/agent` 路由，与 `/mp-staff`、`/billing` 并存。

# 设计约束更新

- 新增侧栏模块时须**追加** `asyncRouterMap` 条目，禁止用新 path 覆盖既有业务菜单（尤其是 `/agent`）。

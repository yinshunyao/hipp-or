# 问题描述

分享页 / 历史会话中用户上传的图片打不开（裂图），仅显示文件名。复现：`http://hipp.site/or/share/...` 中带附图的用户气泡。

例：消息 attachments 仍为  
`https://hipp.site/media/or/.../6583989987ec4598bf6c2f1e9deb8ea1.jpg`，  
盘上文件已不存在，Nginx/manager 返回 404。

# 根因分析

话题结束时 `cleanup_session_media_after_topic_close` 汇总会话 `attachments.url`，只把**助手正文**里出现的 `/media/` URL 当作保留集，其余一律 S2S 删盘。需求分析回复通常不会把用户附图 URL 再嵌进正文，故结题后用户附图被删，消息 JSON 仍指向旧 URL → 裂图。

# 涉及文件

| 文件 | 变更 |
|:---|:---|
| `hipp-or/hipp-api/apps/mp_chat/media_cleanup.py` | 结题保留全部消息 attachments；不再误删历史附图 |
| `01-or` / `02-dr` / `03-tr` 上述文档 | 同步「历史附件须可访问」 |

# 设计约束更新

- 已发送并落在消息 `attachments` 的媒体必须保留至孤儿 GC 判定无引用为止。
- **已删盘的历史文件无法自动恢复**；修复后仅保证新结题会话不再裂图。

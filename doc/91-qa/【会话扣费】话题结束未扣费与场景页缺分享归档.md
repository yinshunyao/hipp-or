# 根因分析

1. **扣费**：先前实现挂在「创建会话 / 首条消息」，与产品语义「完成一次咨询」不一致；话题结束路径未调用 S2S deduct。
2. **按钮**：分享/归档只做在独立会话页 `ChatView` 的 `#extra` 槽；用户日常在 `SceneView`（需求/商业）聊完，该页未挂相同操作。

# 涉及文件

- `hipp-api/apps/mp_chat/crud.py`：话题结束扣费；发送前余额校验；详情补扣。
- `hipp-api/apps/mp_chat/views.py`：发消息前 `assert_dify_session_fee_affordable`。
- `hipp-api/utils/hipp_manager.py`：增加 `s2s_balance`。
- `hipp-web/src/views/SceneView.vue`：右上角分享/归档，与 ChatView 一致。

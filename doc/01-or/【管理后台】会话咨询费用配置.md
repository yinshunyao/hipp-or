# 背景

需求分析与商业评估的每次会话咨询（话题结束计一次）均从共享余额扣费，费率规则相同。费率不应写死在代码里：运营需要可改全局默认金额，并对个别用户单独设定（优惠或加价）。配置入口应在 or 管理端完成。

# 目标

1. 提供全局默认「每次会话咨询费用」配置，默认 0.10 元。
2. 支持按手机号/姓名/昵称搜索用户，并为单个用户设定或清除专属费用。
3. 扣费与用户端展示均以「用户专属优先，否则全局」解析后的金额为准。

# 要求

## 功能性要求

1. 管理端侧栏须可见「计费配置 / 会话咨询费用」入口；可查看与修改全局每次会话费用（单位：元，保留两位小数，须 ≥ 0）。
2. 管理端可搜索用户，列表展示姓名、手机号、是否专属、专属金额、生效金额。
3. 可为用户设定专属金额；可清除专属后恢复跟随全局。
4. 未配置专属时生效金额等于全局；全局未初始化时按 0.10。

## 非功能性要求

1. 仅管理员可改配置；金额非法时拒绝保存。
2. 扣费实现见资金账户需求；配置解析结果须被扣费路径读取。

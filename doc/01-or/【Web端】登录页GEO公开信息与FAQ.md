# 背景

智能需求分析 Web 入口 `https://hipp.site/or/` 未登录时进入登录页。页面几乎只有登录表单，爬虫与生成式引擎难以抽取「产品是什么、做什么、不做边界」。GEO 工作台（`hipp-geo`）已产出实体声明与 FAQ 源稿，需挂到**未登录可读**的官方页面。

# 目标

1. 让未登录用户在登录页即可看到产品实体句、能力摘要、FAQ 与「不做」边界。
2. 提供可分享的 FAQ 文档页（路由与静态 HTML），便于检索与 AI 引用。
3. 文案与 `hipp-geo/products/hipp-or` 实体/FAQ 对齐；登录能力与协议流程不变。

# 要求

## 功能性要求

1. `/login` 左侧（或等价主文区）展示：产品名、一句话能力、**产品优势**、**截图**、精选 FAQ、不做清单；右侧保留短信/密码登录。
2. 新增公开路由 `/faq`（无需登录），展示完整 FAQ、优势与截图；登录页可链到该页。
3. 构建产物含静态 `faq.html`（无 JS 亦可读正文与图），便于爬虫抓取。
4. `index.html` 补充产品向 meta description；可含 FAQPage JSON-LD。
5. 已登录访问 `/` 仍进需求页；未登录进登录页。FAQ/legal 保持公开。
6. 优势表述遵守 workspace `rules-geo-public-advantages.mdc`，不得与「不做」冲突。

## 非功能性要求

1. 客户界面不写软件设计思路与常识废话；边界文案保留。
2. 不改变鉴权、短信、协议勾选逻辑。
3. 文案变更以 `hipp-geo/products/hipp-or/content/` 为真源时，同步改 `hipp-web` 内数据文件。

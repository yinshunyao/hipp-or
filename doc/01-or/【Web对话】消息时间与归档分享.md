# 背景

浏览器里的会话能看往来内容，但每条消息没有时间，事后很难分辨是哪一天说的。已经完成的话题只能自己登录打开，没法把一段咨询记录交给别人看。

# 目标

1. 在会话里展示每条消息的日期和时间。
2. 让已完成的话题生成分享链接，对方不用登录就能只读查看。

# 要求

## 功能性要求

- 用户消息和助手消息都显示日期与时间。刚发出、尚未从服务端带回时间的消息，先用本机当前时间。
- 话题已经结束就可以分享，不要求先放进「归档」。入口在最近列表、归档列表，以及已打开的该话题上（含需求/商业**场景页**右上角，不仅限独立会话详情页）。
- 还在进行中的话题不能分享。
- 分享链接不要求登录。打开后只有该话题的聊天内容和「联系我们」，不出现左侧菜单、最近会话、资料和输入框。
- 「联系我们」仍只弹出关于我们，不进入人工会话。
- 话题被延续、不再是已完成状态后，原链接失效。
- 还没有分享过的已完成话题，点击「分享」生成链接并复制。已经分享过的，按钮改为「复制链接」，只复制原来的链接，不另建一条。
- 已分享的话题可以「停止分享」。停止后原链接失效。之后再分享会得到新链接。
- 点击复制后把链接写入剪贴板。页面不是安全上下文时，用页面内复制，不依赖新的剪贴板接口。复制仍失败时弹出链接，由用户再点一次复制。
- 最近列表、归档列表和已打开话题上，分享、复制链接、停止分享用图标，不把这些词排进按钮。鼠标悬停或键盘聚焦时显示对应名称，点击仍执行原来的分享、复制或停止分享。
- 列表行里的这些图标按钮收成一组，彼此靠拢。按钮之间的空隙小于标题和按钮组之间的空隙，标题尽量多露出几个字。

## 非功能性要求

- 分享页不返回账号、手机号和智能体密钥。
- 链接使用随机令牌，不能靠会话编号依次打开别人的记录。

# 实现要点

## 管理端入口

`asyncRouterMap` 增加 `/billing` → `session-fee`（与人工客服同属常量路由兜底），避免仅靠 DB 菜单遗漏。

## 会话扣费

- 时机：**话题结束**（助手 `结束状态 True` → `is_topic_closed=true`）时 S2S 扣费；创建会话与发消息均不扣。
- 发送前：对未扣费 dify 会话用 S2S balance 校验余额 ≥ 费率（不足拒绝发送）。
- 结束扣费失败：话题仍归档，`fee_charged` 保持 false；打开会话详情时再尝试补扣。
- 金额：`resolve_session_fee`；0 元跳过扣费仍标记已处理。
- S2S：`HIPP_MANAGER_KEY`；`ref_id=or_session_{id}`；会话字段 `fee_charged`。
- 人工客服 / 游客本轮不扣余额。
- 余额不足：提示去 `/wallet` 充值。
- **需求分析与商业评估**同一套扣费（不区分 `service_type`）；仅智能体入口按场景分流。
- 分析见 `会话扣费时机分析报告.md`。

## or 产品账本查询

- `/wallet/transactions`、`/wallet/recharge/orders` 未传 `product` 时默认 `or`。
- 前端账户页请求显式带 `or`；文案注明本产品相关流水；余额仍为账户总余额。

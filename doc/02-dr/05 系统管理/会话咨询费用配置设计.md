# 功能设计

## 数据模型

无 DB 外键；`user_id` 仅逻辑关联 `vadmin_auth_user.id`。

| 表 | 用途 |
|:---|:---|
| `vadmin_or_billing_setting` | 全局键值；`config_key=session_fee`，`config_value` 为金额字符串（如 `0.10`） |
| `vadmin_or_user_session_fee` | 用户专属：`user_id` 唯一，`amount` Numeric(10,2) |

解析规则：`effective = override.amount if 有专属 else global`；全局缺失时 `0.10`。

## 后端 API（`/vadmin/billing`，FullAdminAuth）

| 方法 | 路径 | 说明 |
|:---|:---|:---|
| GET | `/session-fee/global` | `{ amount }` |
| PUT | `/session-fee/global` | body `{ amount }`，≥0，两位小数 |
| GET | `/session-fee/users` | `q` 搜手机号/姓名/昵称；分页；返回专属与生效金额 |
| PUT | `/session-fee/users/{user_id}` | body `{ amount }` 设定专属 |
| DELETE | `/session-fee/users/{user_id}` | 清除专属 |

用户侧（登录）：`GET /wallet/session-fee` → `{ amount, is_override }`，供账户页展示。

公共函数：`apps/vadmin/billing/service.py` → `resolve_session_fee(db, user_id)`，供后续扣费调用。

迁移：dev `e7f8a9b0c1d2`，pro `e7f8a9b0c1d3`；初始化写入 `session_fee=0.10`。

## 管理端页面

- 组件：`views/Vadmin/Billing/SessionFee.vue`
- 路由：`/billing/session-fee`（目录 `/billing` + 页面 `session-fee`）
- 上方：全局费用表单；下方：搜索 + 用户表格（设定/清除）
- **入口兜底**：`hipp-admin` 的 `asyncRouterMap` 硬编码挂载该页（与人工客服同模式），避免现网 DB 菜单未配置时侧栏不可见。

### 菜单配置要点（可选，便于菜单管理维护）

- 目录 `menu_type=0`：`path=/billing`，`component=#`
- 页面 `menu_type=1`：`path=session-fee`，`component=views/Vadmin/Billing/SessionFee`

# 约束与边界

- 不在此页做充值或扣费执行（扣费见个人资金账户设计）。
- 金额单位为元，存储与展示均为两位小数。

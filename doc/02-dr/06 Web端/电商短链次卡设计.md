# 功能设计

## 分层

| 层 | 模块 | 职责 |
|:---|:---|:---|
| 渠道 | `apps/commerce/channels/xhs.py` | 验签（可配置跳过联调）、解析订单消息、调用发货回写 |
| 履约 | `apps/commerce/service.py` | `channel+external_order_id` 幂等落单并出权益 |
| 权益 | `vadmin_or_entitlement` | token 状态机；绑定用户/会话；话题结束 → used |
| 核销 | `POST /commerce/access/{token}/redeem` | 签发 `user_type=entitlement` JWT（仅 unused/bound） |
| Web | `/a/:token` | 预检 → 可聊则 redeem 后页内对话（bare，无侧栏树）；已 used 则公开只读正文 |

## 数据模型（无 DB 外键）

### `vadmin_or_entitlement`

| 字段 | 说明 |
|:---|:---|
| token | 短链令牌，unique |
| status | `unused` / `bound` / `used` / `void` / `expired` |
| service_type | 固定 `需求分析`（与智能体一致） |
| channel | `manual` / `xhs` / … |
| external_order_id | 渠道订单号；manual 可空 |
| bound_user_id | 核销后临时用户 |
| bound_session_id | 首次建会话后绑定 |
| expires_at | 可空=不过期 |
| used_at / void_at / remark | 审计 |

唯一：`(channel, external_order_id)` 在 `external_order_id` 非空时唯一（应用层 + 索引）。

### `vadmin_or_channel_order`（管理端「电商渠道订单」真源）

| 字段 | 说明 |
|:---|:---|
| channel / external_order_id | 幂等键 |
| sku_code | 可选商品标识 |
| status | **`paid` 已支付 / `redeemed` 已核销 / `refunded` 已退费** |
| entitlement_id / short_url | 关联短链 |
| paid_at / redeemed_at / refunded_at | 节点时间 |
| refund_remark / refund_operator | 管理端退费备注与操作人 |
| deliver_ok / deliver_payload / raw_event | 发货回写与联调 |

展示文案：`paid`→已支付，`redeemed`→已核销，`refunded`→已退费。

## 状态机

```text
权益： unused --打开短链--> bound --话题结束--> used
         |                    |
         +------- 退费 void --+

订单： paid --话题结束--> redeemed
         |                  |
         +----- 管理端退费 --> refunded（短链作废）
```

说明：打开短链只绑定，不算订单核销；**咨询话题结束**才订单→已核销。退费不调用站内钱包；运营须在千帆完成真实退款。

## API

| 方法 | 路径 | 鉴权 | 说明 |
|:---|:---|:---|:---|
| POST | `/commerce/access/{token}/redeem` | 无 | 进行中打开短链签发 JWT（非订单核销）；已 used 拒绝 |
| GET | `/commerce/access/{token}` | 无 | 预检：`mode=chat` 或 `mode=readonly`（已核销时带 title/messages，免登录） |
| POST | `/commerce/channels/xhs/notify` | 平台签名/联调开关 | 订单回调 → 已支付+短链 |
| GET | `/vadmin/commerce/orders` | FullAdminAuth | 渠道订单流水 |
| POST | `/vadmin/commerce/orders/offline` | FullAdminAuth | 线下出链：1 次需求分析短链，订单 `channel=offline`、状态已支付 |
| POST | `/vadmin/commerce/orders/{id}/refund` | FullAdminAuth | 退费：短链失效，状态已退费 |
| GET/POST/… | `/vadmin/commerce/entitlements*` | FullAdminAuth | 短链辅助列表/批量生成 |

管理端「渠道订单」页提供「线下出链」按钮：可选备注与有效天数，成功后复制短链并刷新列表。

## 用户与计费

- `user_type=entitlement`：跳过 manager 在线校验与钱包扣费；禁止充值。
- 建会话/发消息：仅允许 `service_type=需求分析`；已 `used`/`void`/`expired` 禁止新建。
- 话题结束：`fee_charged=true` 且权益 → `used`，对应渠道订单 → `redeemed`（不 S2S deduct）。
- 不走 `mp_guest` 免费次数。

## Web

- 路由 `/a/:token` 无 `meta.auth`、无 `shell`（布局对齐 `/share/:token`：全屏 `ChatPane bare`）。
- `GET` 若 `mode=readonly`：直接展示消息，不签发 JWT。
- `mode=chat`：`redeem` → 页内建/开需求分析会话；无新会话、无归档、无分享按钮；话题结束后切只读并提示「可将本链接分享给他人」。
- 若次卡 JWT 误入带 shell 的 `/requirement`：侧栏隐藏「最近 / 新会话 / 归档 / 商业」；场景页隐藏分享/归档。
- 短链对外基址：`HIPP_OR_ACCESS_BASE`（现网 `https://hipp.site/or/a`）。
- 管理端列表：状态/渠道展示中文（`status_label` / `channel_label`）；操作含「复制链接」「退费」（未消费短链作废并同步订单已退费）。

## 小红书 Adapter（MVP）

1. 回调入库事件 → `fulfill_order(channel=xhs, order_id=…)` → 生成权益。
2. 拼短链 `{ACCESS_BASE}/{token}`，调用可配置的发货 HTTP（未配置则记 `delivered` 仅落库，管理台可查链）。
3. 售后事件可触发退费作废；管理端也可主动退费。

## 环境变量

| 变量 | 用途 |
|:---|:---|
| `HIPP_OR_ACCESS_BASE` | 短链前缀 |
| `HIPP_XHS_APP_KEY` / `HIPP_XHS_APP_SECRET` | 开放平台凭证 |
| `HIPP_XHS_SKIP_SIGN` | 联调跳过验签（默认 false） |
| `HIPP_XHS_DELIVER_URL` | 可选自建/代理发货 URL；空则只落库 |

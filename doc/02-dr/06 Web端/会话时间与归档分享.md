# 功能设计

## 消息时间

`GET /mp/chat/sessions/{id}/messages` 已返回 `create_datetime`。页面在用户气泡和助手气泡下展示 `YYYY-MM-DD HH:mm`。刚在本页发出、还没有服务端时间的消息，用发送当时的本机时间。

## 归档分享

`vadmin_chat_session` 增加可空字段 `share_token`（最长 64，唯一）。迁移 dev `d5e6f7a8b9c1`、pro `d5e6f7a8b9c2`。生产库的 `alembic_version` 停在仓库里没有脚本的 `4fefc377b9b8`，pro 用同名空迁移接上，再加分享字段。`python main.py migrate` 还会按模型再生成一条修订；若它清掉 `is_archived`、`token_usage` 的默认值，用 `f6a7b8c9d0e1` 补回，避免旧进程插入会话失败。

- `POST /mp/chat/sessions/{id}/share`：须登录且为会话主人。仅 `is_topic_closed` 为真时生成或返回已有令牌。已有令牌时不更换。不看 `is_archived`。响应 `{ share_token }`。
- `DELETE /mp/chat/sessions/{id}/share`：须登录且为会话主人。清空 `share_token`。之后原链接失效。
- `GET /mp/chat/share/{token}`：不校验登录。令牌对应已完成且未删除的会话时，返回标题和消息（`role`、`content`、`create_datetime`）。话题已延续、已停止分享或令牌不存在时，业务码表示分享不存在。不返回用户资料、Dify 地址和密钥。

会话列表和详情增加 `is_shared`（有令牌则为真），不把令牌放进列表。前端在最近列表、归档列表、独立会话页（`ChatView`）以及需求/商业场景页（`SceneView`）右上角用图标：未分享是分享图标，悬停提示「分享」；已分享是链接图标和停止图标，悬停提示「复制链接」和「停止分享」。场景页在 `meta.topicClosed` 时显示分享；未用户归档时显示「归档」。最近列表和归档列表里，这些图标和归档图标放在同一组，按钮边长约 22px，组内间距 2px，小于标题和按钮组之间的间距。复制把 `{当前站点}{BASE_URL}share/{token}` 写入剪贴板：先用页面内 `document.execCommand('copy')`，安全上下文下再试剪贴板接口。两次都失败时弹出链接和「复制」按钮。

路由 `/share/:token` 不要求登录，也不使用左侧导航。页面只渲染该话题的消息和「联系我们」。联系我们弹出与会话页相同的关于我们。没有输入框，不能发送。

# 约束与边界

- 不改变归档、发送、登录的原有路径。
- 小程序不增加分享入口；接口可被调用，但不要求小程序改版。

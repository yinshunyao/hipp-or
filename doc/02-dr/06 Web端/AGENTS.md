# `hipp-or/doc/02-dr/06 Web端/` 目录说明

## 目录用途

存放浏览器用户端（`hipp-web`）的开发设计，说明页面、接口用法与边界。含电商短链核销（`电商短链次卡设计.md`）。

## 文档范围

- 允许：页面结构、与现有 `/auth`、`/mp/chat`、`/commerce`、当前用户接口的对应关系、交互与约束。
- 禁止：改写原始需求；测试步骤放在 `../../03-tr/06 Web端/`。

## 编辑规则

- 每个设计文档须含 `# 关联文档`，至少关联一条 `01-or`。
- 变更设计时同步更新对应测试设计。

## 协作约定

- 后端对话语义以 `../04 小程序对话/` 为准；本目录只描述 Web 端如何消费这些接口。

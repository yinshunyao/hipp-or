# 状态

- **当前**：多模态主路径已落地；附件存储改为 **hipp-manager 公共媒体**（修复直连 OSS 占位配置导致上传失败）。
- **运维注意**：确认 `MEDIA_PUBLIC_BASE` 与 Nginx `/media/`、`/api/media/` 体大小；Dify 出口可读媒体 URL；可选 `HIPP_OR_DIFY_CHAT_LOCAL_FILE=1` 启用 local_file 降级；孤儿 GC 默认开（`HIPP_OR_MEDIA_GC`/`_HOUR`/`_MIN_AGE_HOURS`），须 Redis 与 `HIPP_MANAGER_KEY`。

# 范围与不做

- **做**：平台媒体上传（manager）、or 门面校验、remote_url 转发、消息 attachments、Web+Uni 附件与语音转写、Dify 两应用开关与限额对齐、合计 &lt;20MB。
- **不做**：视频、人工客服附件、客户端直连 Dify、仅 query 贴 URL、对话附件再直连本产品 OSS。

# 阶段计划

## 阶段 0 — 运营与配置（可先于代码）

1. 在 Dify 控制台按 `study/配置信息/生产-yin/dify/导入说明.md` 导入 **多模态 v2**（`v2/需求分析.yml` / `v2/商业评估.yml`）：文件上传（image+document、remote_url）；Code 读纯文本 + 按需视觉解析；收集关 vision，用 `survey_state`/`attach_turn`；方案读 `attach_digest`；按需 STT。纯文字回退用 `v1/`。子路径 Monaco/`data-base-path` 见同目录 `部署说明.md`。
2. 确认单图/单文件/个数上限；与产品合计 &lt;20MB 写入设计常量表。
3. 用公网 `/media/` 测试图验证 Dify `remote_url` 可达；不可达则启用设计中的 `local_file` 降级开关。
4. 控制台改完必须回写仓库：`v2/需求分析.yml` / `v2/商业评估.yml`；提示词按「附件解析 / 收集 / 方案」三分文件维护于 `v2/`。

## 阶段 1 — API 竖切

1. Alembic：`vadmin_chat_message.attachments`（JSON 文本，可空）。
2. `POST /mp/chat/upload` + 大小/类型校验 + 转发 manager `/api/media/upload`。
3. `dify_client` 支持 `files`；blocking / stream / WS 三路径读 `files`。
4. 落库 user 消息写 `attachments`；预览规则；`ChatMessageOut` 返回附件。
5. （可选同阶段）`POST /mp/chat/audio-to-text`。

## 阶段 2 — Web

1. 上传与待发预览；发送带 `files`；输入区粘贴/拖拽入附（与点选共用校验与上传）。
2. 历史/分享气泡渲染。
3. 录音 → 转写 → 填入输入框。

## 阶段 3 — 小程序

1. 对齐 Web 的上传/发送/渲染（API 能力差异处降级提示）。
2. 录音与转写；真机与域名白名单（upload、OSS、wss）。

## 阶段 4 — 联调与收尾

1. 按 TR 用例过图+文档+超限+纯附件+语音。
2. OR「当前工作项」迁「已完成」；`99-ops/release-note-draft.md` 记一条。
3. 若有设计偏差，回写本方案与 DR。

# 关键接口与表（摘要）

| 项 | 说明 |
|:---|:---|
| `POST /mp/chat/upload` | 鉴权校验 → manager 媒体绝对 URL |
| `POST /mp/chat/audio-to-text` | 鉴权录音 → 文本 |
| 发送 body | `{ query, files? }` |
| 表字段 | `vadmin_chat_message.attachments` |
| Dify | `files[]` + `remote_url` |

# 部署注意

- 生产须配置 manager `MEDIA_PUBLIC_BASE`，Nginx 放行 `/media/` 与足够大的 `/api/media/` body；Dify 出口须能 GET 媒体 URL。
- 小程序需配置 uploadFile 合法域名（API 与媒体域名，通常同站 `hipp.site`）。
- Dify 应用须**发布**后 API 才吃到新 file_upload / vision。
- 不在文档中写入 AccessKey、桶内真实客户路径等敏感信息。

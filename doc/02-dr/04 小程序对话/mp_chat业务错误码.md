# 功能设计

`mp_chat` 业务失败须同时返回 **`code` + `message`**（HTTP JSON 与 WebSocket `event=error` 一致）。常量真源：`hipp-api/apps/mp_chat/biz_codes.py`；Web 镜像：`hipp-web/src/utils/bizErrors.js`。

## 码表（46001+）

| code | 含义 | 默认 message | 前端处理 |
|:---|:---|:---|:---|
| 46001 | 智能体不可发送 | 智能体已下架或删除，暂不支持继续对话 | 会话只读 |
| 46002 | 话题已结束 | （服务端完整引导文案） | 引导新话题 / 继续对话 |
| 46003 | 场景无可用智能体 | 当前场景暂不可用 | 禁用发送 |
| 46004 | 游客体验用尽 | （引导登录文案） | 引导登录 |
| 46010 | 短链无效或过期 | 分析链接无效或已过期 | 提示失效 |
| 46011 | 次卡已用尽 | 本次分析次数已用完 | 提示已用完 |
| 46012 | 短链已作废 | 分析链接已作废 | 提示作废 |
| 46013 | 次卡场景不符/超额 | 当前链接仅可用于需求分析，或次数已用尽 | 提示限制 |
| **46005** | **余额不足** | **余额不足，请先前往账户充值后再发起咨询** | **展示文案；Web 跳转 `/wallet`** |
| **46006** | **扣费预检失败** | 无法校验余额 / 未绑定手机号等 | 展示文案；可稍后重试，不去充值页 |

历史：费用相关曾统一为 `46005`；现「余额不足」固定 `46005`，「无法校验/未绑手机」为 `46006`。

触发点（同一套码）：`POST /mp/chat/sessions` 创建前、`GET /mp/chat/session-fee-precheck`（空草稿 / 新会话复用前）、发消息（HTTP/WS）。

## 通道

- HTTP：`{"code":46005,"message":"..."}`（经 `CustomException`）。
- WebSocket：`{"event":"error","code":46005,"message":"..."}`。

前端可行动逻辑**只认 `code`**；展示优先用服务端 `message`，空则用前端码表兜底。

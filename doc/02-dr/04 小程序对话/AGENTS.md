# `hipp-or/doc/02-dr/04 小程序对话/` 目录说明

## 目录用途

存放小程序对话（及与之共用的 `/mp/chat` 后端语义）相关开发设计。

## 文档范围

- 允许：会话/消息、收件箱、场景页、导航与我的、多模态附件等设计。
- 禁止：替代 OR；测试步骤放在 `../../03-tr/04 小程序对话/`。

## 编辑规则

- 每个设计文档须含 `# 关联文档`，至少一条 `01-or`。
- 变更设计时同步更新对应测试设计；经确认的实施方案可放本目录，文件名含「实施方案」。

## 协作约定

- Web 端页面消费方式见 `../06 Web端/`；接口与落库真源以本目录为准。
